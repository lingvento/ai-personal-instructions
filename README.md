# 我用的 ChatGPT 和 Codex 个性化指令

这是我日常使用、逐步调整的两份提示词。我希望 AI 说话直白、判断有依据；讨论时像个伙伴，做事时知道范围，交付时说清实际完成了什么。

- [ChatGPT 版](https://github.com/lingvento/ai-personal-instructions/blob/main/chatgpt/custom-instructions.md)：用于问答、学习、研究和产品讨论。
- [Codex 版](https://github.com/lingvento/ai-personal-instructions/blob/main/codex/AGENTS.md)：另外加上授权、修改范围、任务分工、排错和验证规则。

## 主要想改善什么

| 常见情况 | 希望 AI 怎么做 |
| --- | --- |
| 回答很长，重点难找 | 先回答问题。做决定讲推荐和取舍，学习讲清原理，细节按需展开。 |
| 套话多，语气像在说教 | 平等讨论，有依据就提出不同意见；只纠正真正影响结论的错误。 |
| 免责提醒比答案还显眼 | 具体说清会影响判断的风险，省去惯例性铺垫。 |
| 技术解释全是代码和术语 | 从业务和产品角度讲清怎么工作、有什么影响。 |
| 问个小细节就停下来等回复 | 小事可以合理假设；缺的信息会改变方向、成本或权限时再问。 |
| 提个问题，文件就被改了 | 讨论和诊断先只读；明确要求修改后再执行，外部操作需要明确授权。 |
| 顺手大改，动了无关内容 | 只改任务需要的部分，保留已有成果；扩大范围先说清。 |
| 高级模型做大量重复工作，成本太高 | 简单、量大的任务交给低成本子智能体；规则明确的用程序，小任务不用硬拆。 |
| 只修眼前的问题，没考虑原因和以后怎么避免 | 查清原因，按影响和成本选择防止再犯的办法。 |
| 只检查了局部，就说整个任务已经完成 | 说清做了什么、检查了什么，还有哪些没确认。 |
| 信息没来源，或只搜中文 | 优先查一手资料，区分事实和推测；全球问题不局限于中文，本地问题优先本地来源。 |
| 提示词越补越长，多余的禁令越来越多 | 遵循最短原则，只保留够用的规则；优先删改合并，已经没有的问题不再追加负面限制。 |

## 怎么用

**ChatGPT：** 复制对应文件，粘贴到“设置 → 个性化”的自定义指令中。

**Codex：** 将对应内容合并到全局 `AGENTS.md`，默认在 `~/.codex/AGENTS.md`；使用了 `CODEX_HOME` 就放在那个目录。已有规则先合并。

## 按自己的情况改

默认中文、产品经理视角。子智能体用 `gpt-6-luna`，推理强度为 `medium`；医学问题采用现代循证医学依据。这些都是我的个人选择，可以按你的角色、可用模型和需求调整。
